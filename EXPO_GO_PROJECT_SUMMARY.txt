🔗 API INTEGRATION
================================================================================

The app connects to your backend via REST API.

Required Endpoints:
  
  Projects:
    GET    /api/projects              - Get all projects
    GET    /api/projects/:id          - Get project detail
    POST   /api/projects              - Create project
    PUT    /api/projects/:id          - Update project
    DELETE /api/projects/:id          - Delete project
  
  Entities (Assets):
    GET    /api/entities?type=...     - Get entities (characters, props, etc)
    GET    /api/entities/:id          - Get entity detail
    POST   /api/entities              - Create entity
    PUT    /api/entities/:id          - Update entity
    DELETE /api/entities/:id          - Delete entity

Configure API URL in mobile/.env.local:
  EXPO_PUBLIC_API_BASE_URL=http://your-api.com/api

📱 HOW TO RUN
================================================================================

Development (Recommended):
  1. cd mobile
  2. npm install
  3. npm start
  4. Scan QR code with Expo Go app
  → App opens instantly!

iOS Simulator (Mac only):
  1. cd mobile
  2. npm install
  3. npm start
  4. Press 'i' in terminal
  → Opens iOS Simulator

Android Emulator:
  1. cd mobile
  2. npm install
  3. npm start
  4. Press 'a' in terminal
  → Opens Android Emulator

Web Browser (Limited features):
  1. cd mobile
  2. npm install
  3. npm start
  4. Press 'w' in terminal
  → Opens in web browser

Production (iOS):
  npm run build:ios
  → Generates .ipa for App Store

Production (Android):
  npm run build:android
  → Generates .aab for Play Store

🎯 STATE MANAGEMENT (ZUSTAND)
================================================================================

Three main stores for state management:

projectStore.ts:
  • projects: Project[]
  • loading: boolean
  • error: string | null
  • Actions: fetchProjects, createProject, updateProject, deleteProject

libraryStore.ts:
  • assets: Entity[]
  • loading: boolean
  • Actions: fetchAssets, addAsset, deleteAsset, searchAssets

userStore.ts:
  • user: User | null
  • notifications: boolean
  • Actions: setUser, setNotifications, logout, loadUserFromStorage

Import and use anywhere:
  import { useProjectStore } from '@/stores/projectStore';
  const { projects, loading } = useProjectStore();

🐛 TROUBLESHOOTING
================================================================================

Port Already in Use:
  npm start -- --port 8082

Cache Issues:
  npm start -- --clear

Module Not Found:
  rm -rf node_modules && npm install && npm start -- --clear

QR Code Won't Scan:
  1. Enter URL manually from terminal
  2. Check device WiFi
  3. Restart Expo Go app

API Connection Issues:
  1. Check EXPO_PUBLIC_API_BASE_URL in .env.local
  2. Ensure backend is running
  3. On Android emulator: use 10.0.2.2 instead of localhost

More help: See EXPO_SETUP_GUIDE.md → Troubleshooting section
